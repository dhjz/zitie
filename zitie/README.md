# zitie · 字帖工坊

纯前端离线字帖生成器。双击 `index.html` 就能用，不需要安装、打包或联网。

## 目录

```
index.html        根组件模板
static/
  app.css         界面样式 + 打印版面
  utils.js        工具层：笔顺解码 / 拼音 / 出题 / 分页排版
  store.js        配置层：schema 注册表、自动保存、导出导入、恢复默认
  ui.js           组件层：控件、A4 纸张、格子
  index.js        入口：路由、主题、装配
  page.*.js       各功能页（自注册进 window.myComponents）
  collection.js   素材合集：弹窗、页签、方格点选与复制
  page.settings.js 设置弹窗：导出 / 导入 JSON、恢复默认
  data/           笔顺数据、拼音引擎、素材合集数据、课文生字表
  fonts/          中文六款、英文四款、拼音两款、控笔线条一套
```

## 加一个页面

1. 拷一份 `static/page.hanzi.js`，改成 `page.xxx.js`
2. 在 `DEFAULTS` 底下加一行 `Z.settings.define('xxx', { label, defaults: DEFAULTS, inputs: ['content'] })`
3. 末尾写 `window.myComponents.XxxPage = XxxPage`
4. `index.html` 里补 `<script src="static/page.xxx.js">`
5. `static/index.js` 的 `ROUTES` 加一项，模板里加 `<xxx-page v-else-if="route === 'xxx'">`

`index.js` 本身不用改 —— 组件是自注册的。

首页那张缩略图同理：`ui.js` 里的 `THUMBS` 加一份该页的小样数据
（几行几列、哪些字描红），`page.home.js` 的 `features` 里加一张卡就成。
缩略图是 SVG 按真实字帖比例画的，不拉笔顺分片。

## 中文字体：描字走字体，笔顺走笔画

汉字字帖的「字体」选择只对描字有效，因为它和笔顺是两条完全不同的渲染路径：

- **描字（`render: 'text'`）** 用 SVG `<text>` 按选中字体整字画。选隶书就是隶书，选行楷就是行楷。
- **笔顺（`render: 'stroke'`）** 画的是笔顺数据里的笔画轮廓路径，一个字拆成一笔一笔。数据只有楷体那一套，所以笔顺模式下字体选项没有意义 —— 换到非楷体时「笔顺」会置灰。

词语文章页同理，整段文字只走字体（`genStage` 固定 `render: 'text'`），
逐笔拆一整篇课文既看不出来也没必要。

顺带一个性能收益：描字和词语文章不再需要笔顺分片，`useGen` 的 `strokes` 判定会让它直接跳过预取。

### 六款字体怎么对齐到同一个格子

各款字体在 em 框里画得多满差很多 —— 隶书的字只占 em 高 65%，仿宋能到 98%，
行楷还往下探出 20%。字号直接取格子边长，同一版面上就会「有的顶天立地、有的瘦一圈」。

所以 `Zu.fontMetric(key)` 会用 canvas `measureText` 量一批常用字的墨迹包络
（95 分位，避开「永」「春」这类挑出去的字），反算两件事：

- `scale`：字号缩放，让墨迹占格子的 88%（留出走笔空间）
- `baseline`：基线位置，让墨迹中心落在格子正中

量好缓存起来，字体是 `FontFace` 异步注入的，所以先给个近似值、量完 bump `Zu.metricRev` 让字形重排。
用 canvas 而不是 SVG `getBBox` —— 后者在 Chrome 里返回的是 em 框（永远 1000×1000），量不出实际墨迹。

## 格型、描字类型、页脚、订正格

这四项都是「加一个选项就看得见」的那种，落在 `doc` 上，`ZSheet` 照着画。

**格型**（`doc.guide`）是 `.cell-guide` 上的一个 class，纯 CSS：

| key | 名字 | 画法 |
|---|---|---|
| `tian` | 田字格 | 十字虚线 |
| `mi` | 米字格 | 十字 + 对角线 |
| `hui` | 回宫格 | 内缩虚框 |
| `cross` | 交叉格 | 只有对角线 |
| `fang` | 方格 | 只有外框 |
| `jiu` | 九宫格 | 四线切九块 |
| `shuang` | 双横线 | 抄写本横线页，去掉竖线 |
| `wu` | 无格 | 一片白纸 |

九宫格那四条线用四层 `linear-gradient` 画，不用伪元素 —— 只有两个伪元素，不够切九块。

**描字类型**（`doc.trace`）只作用在「字体整字」这条渲染路径上，示范格永远是实心：
CSS 描不了字形轮廓，但 SVG 的 `stroke` + `stroke-dasharray` 可以，
空心 = 描边填充、细虚线 = 长 dash、圆点 = `dasharray: 0 40` 配 `linecap: round`。
一条属性换三种字帖，不用另存一套空心字体。笔顺帖画的是笔画轮廓，这个选项对它没意义。

**页脚**（`doc.foot`）是姓名 / 班级 / 日期几栏横线，给交作业用。页码一直有，
开了页脚就压到右边，不跟姓名挤。

**订正格**（`doc.fixH`）每页底部留一行「改错」区。高度不是白送的：`gridFor` 多收一个
`reserve` 参数，先把它从版心里扣掉再排行数，所以格子照样铺满、不会多出一页来。
页脚和订正格都只在 `doc` 上挂字段，各页面把选项原样传进去，不着渲染层的事。

## 间隔描字、拼音格样式、空段、逐字注音

第一梯队那四项是「加个选项就看得见」，第二梯队这四项动的是排版的节奏。

**间隔描字**（`form.row_pattern`）一行一个记号，`描`/`空`（也认 `t`/`b`、`1`/`0`）。
「描描空」就是这个字印两行淡字、留一行自己写。填了它就不看「几行描 + 几行空」；
模式的第一行兼作示范行，第一个格子深色、其余淡色。最多 8 行。
笔顺帖不走这条路 —— 那儿一格里是一笔，跟「一行整字」不是一个东西。

**拼音格样式**（`doc.pyStyle`）只换拼音行那条线的画法，格子尺寸不动：
`grid` 虚线格（默认）、`under` 下划线、`paren` 小括号、`box` 长方格。
四种都是 `.cell-py` 的伪元素，`ui.js` 只负责把 class 挂上去。

**空段符号**（`□`）在词语文章页生效：单起一行只写 `□`，那一行就留成空白格，
写几个空几行。`genStage` 里 `isBlankLine()` 先认出来，直接铺满一行空格子再 `continue`。

**逐字注音**（`form.pinyin_fix`）是 pinyin-pro 的补丁口。汉字页「改拼音」展开一排小格子，
一个字一个输入框，`{ 字: 'pīn' }` 只存改过的；改回跟自动注音一样就删掉那个键。
`genHanzi` 里先查这张表，查不到才用 pinyin-pro 的结果。

顺手修了一个老 bug：`genHanzi` 原来按「第几个不重复的字」去取拼音，
内容里一出现重复字，后面的音就全串了一位。现在按 `pinyinList` 的分位对齐取。

## 配置的保存与搬家

每个页面的参数改完自动存本机，刷新还在。这件事统一在 `static/store.js` 里的 `Z.settings`：

- **页面自描述 schema**。每个 `page.*.js` 在 `DEFAULTS` 底下写一行
  `Z.settings.define('xxx', { label, defaults: DEFAULTS, inputs: ['content'] })`，
  store 不复制默认值，也不猜字段。
- **`inputs` 是输入类**：正文（`content`）、逐字注音（`pinyin_fix`）这类不落盘、也不进导出的 JSON。
  表格的排版规则（比如 `row_pattern` 间隔描字）算配置，照常保存。
- **清洗靠默认值的类型**。只认 `defaults` 里声明过的键，`typeof` 对齐默认值 ——
  删过的旧字段、手改坏的 json 自然出局。
- **保存挂在 `useGen` 的防抖 watch 上（300ms）**，不挂在 `generate` 里：
  以前校验不过（比如正文清空）就直接 return，顺带把刚改的格型颜色一起丢了。

顶栏齿轮里是出口和入口：导出 JSON（带亮暗主题）、导入 JSON、恢复默认。
导入和恢复都会整页刷新 —— 页面各自持有一份 `form`，逐页去改容易留下半新半旧的中间态。

## 三个约定

- **数据模型渲染，不拼 HTML 字符串**。`utils.js` 的 `gen*` 函数算出每页有哪些格子，`ui.js` 的组件负责画。原站是 PHP 返回 HTML 再 `v-html`，改一个格子样式得动后端。
- **分页按块切**。一个字的所有练习行是一个块，`paginateBlocks` 保证它不会被页边界切断。
- **纸张锁 297mm**。预览和打印共用同一套尺寸，`app.css` 里的 `@media print` 只负责把界面藏掉。
- **英文格的字号不写死**。`utils.js` 的 `Z.GLYPH_METRICS` 里放着六款英文/拼音字体的 asc / xh / desc 和逐字宽度，`enLayout()` 按它算出字号与两条内线的位置。换字体、调行高都不用再改数字。

## 英文/拼音格的排版

四线三格的字号是量出来的：

```
size = (格高 - 0.3mm) / (asc + desc)     # 升部顶贴格顶、降部底贴格底
上边线 = asc - xh                        # 小写字母正好卡进中格
下边线 = asc                             # 基线
```

`asc` / `xh` / `desc` 是字体文件里量出来的真实字形高度（`Z.GLYPH_METRICS`），不是估的。以前每款字体手调一个 px（17 / 20 / 22），各家 x 高度差近一倍，纸上就是一溜小字浮在格中间。

加一款英文字体的话，用 `fontTools` 量一下这三个数、按 `Z.EN_CHARS` 顺序把字宽抄进 `adv`，再往 `Z.EN_FONTS` 加一条即可。

## 素材合集

顶栏右上角的「素材合集」是一堆现成的练字素材：小学一到六年级上册/下册生字表（11 份）
加国学三篇（三字经、弟子规、千字文）。按年级分页签，点开一条，正文摊成一个个紧凑小方格。

这一页只是**参考书**，不跟任何字帖页面搭线 —— 不写 localStorage、不发事件、不跳路由。
用户看点方格挑字，点中的高亮，再点取消，按「一键复制」把选中的字和标点带走，
自己去粘到汉字字帖或词语文章里。一个都不选时，「一键复制」就是整篇。

不自动填入是刻意的：素材有 14 份、目标页有 6 个，谁该填到哪儿说不清，
而复制粘贴是用户本来就懂的动作，不用教。

- 选中状态只记字符在全文里的序号，跟排版无关；复制时按原文的行把这行里选中的字符拼回去，
  国学那种一句一行的，粘贴出来还是一句一行。
- 复制优先走 `navigator.clipboard`；双击 `index.html` 打开是 `file://`，不算安全上下文，
  API 直接不可用，这时退回 `textarea + execCommand('copy')`。

数据在 `data/collections.js`，来源是 `../zivip/download/` 那 14 张下载页的正文 ——
也就是原站那批 PDF 字帖的内容本身。分年级生字是纯汉字串（原站就是这么排的），
国学保留标点、按 12 字断行。

### 课文生字

各年级页签下除了上面那几份素材，还多一条「XX 上册/下册 课文生字」，点进去按课列：
左课次、右生字串。点某一课摊方格挑字，跟素材完全一样；底部「整册复制」按课一行一行
把整册拼出来，粘到词语文章里正好一课一行。

数据在 `data/lessons.js`（`window.ZITIE_LESSONS`），11 册 245 组，口径是统编（部编）版
各册识字表：一课一条，只收该课生字。一年级上册按教材的识字/拼音/课文/进阶四块分单元，
其余十册逐课。

一年级下册没按课拆 —— 手上只有全册生字串，硬凑课次只会编。它仍然在素材合集里
以「一年级下册」整册出现，够用；等拿到逐课的识字表再补一册进来。

这一页仍然只是参考书，不跟字帖页面搭线 —— 复制走，用户自己去粘。

## 数据

- `data/strokes.js`：6763 个 GB2312 字的笔画路径，base36 增量编码。只建「字 → 偏移」索引，用到才解码（100 字约 1ms）。
- `data/pinyin-pro.js`：pinyin-pro UMD，词组级多音字判断。

## 控笔练习

`static/fonts/pen/PenControl.woff2`（4.3KB）是一个图标字体，码位对应 32 个线条图形：
`123456789ABCDEFGHIJKLMNOPQRSTUVW`（没有 `0`、`X`、`Y`、`Z`）。

这些图形天生就是「一个格子」的尺寸，所以不做 SVG，直接把字符当文字画：
`static/page.pen.js` 出表单，`Zu.genPen()` 排版，`<z-cell-pen>` 渲染。
换格子大小就是改 `font-size`，打印出来仍然是矢量的。

**输入方式是一个 textarea**，不是「勾选一串图形」。一行一个图形字符，回车就是一行空白，
所以复制、剪切、粘贴、删掉某一行都跟编辑普通文本一样。下面的图形按钮点一下插到
**光标所在位置**（点按钮时输入框会失焦、`selectionStart` 会归零，位置自己记着）；
从没点进过输入框就插到末尾。一行里写几个字符就是几行纸，小写 `a-w` 自动转大写。

**每行格子是铺满的**。格子边长只是基准：先按 `184mm / (边长 + 间距)` 反算列数，
再把 184mm 摊给这些列（`doc.cellW`），行数同理按摊出来的列宽反算 ——
不然右边会剩下半列空地，纸上看着像没印完。想让「前面描红、后面自己写」，
把「描红格数」从 0 改成 6 就行，那 6 格之后留白。

一个坑：字体的线条是「细长矩形」，横线只有 0.9% em 高，12mm 的格子算下来不到 0.02mm，
屏幕上直接消失、纸上也会被打印机吃掉。所以 `.cell-pen` 加了 `-webkit-text-stroke: .07mm`，
落在纸面上大约一根细线的粗，正好适合描。
